# FlappyBird Game

A simple FlappyBird game implemented in Python using Pygame and Flask for web browser play. This game features custom-drawn sprites and a scrolling background.

## Features

- Classic FlappyBird gameplay
- Custom sprites and backgrounds
- Web browser interface
- Responsive controls

## How to Play

1. Clone the repository
2. Install the required packages: `pip install pygame flask`
3. Run the game: `python flappy_bird/flappy_bird.py`
4. Open your browser and navigate to `http://localhost:52328`
5. Click or press any key to make the bird jump
6. Avoid the pipes and don't hit the ground!

## Game Controls

- Click or press any key to make the bird jump
- When game over, click or press any key to restart

## Implementation Details

- Built with Python, Pygame, and Flask
- Custom-drawn sprites using Pygame
- Web interface using Flask and JavaScript
- Real-time game state updates
